Stylemeter, a style meter for Hollow Knight: Silksong.

Install
1. Install BepInEx 5 (the x64 build, 5.4.23 or newer) into the game folder and start the game once.
2. Unpack this zip into the game folder, so the plugin is at BepInEx/plugins/Stylemeter/Stylemeter.dll.
3. Start the game. Options > Stylemeter opens the settings: the points multiplier and every bonus.

Uninstall: delete BepInEx/plugins/Stylemeter.

Settings are also in BepInEx/config/com.glowystar.stylemeter.cfg.
How scoring works, every bonus, pictures and help: https://github.com/GlowyStar/silksong-stylemeter
