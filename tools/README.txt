Stylemeter, a style meter for Hollow Knight: Silksong.

Install
- The download with BepInEx (Stylemeter-<version>-with-BepInEx.zip): unpack it into the game folder, the one with
  "Hollow Knight Silksong.exe", so that winhttp.dll lands next to the exe. Start the game. That is all.
- The download without it (Stylemeter-<version>.zip), for a game that has BepInEx 5 already: unpack it into the game
  folder, so the plugin is at BepInEx/plugins/Stylemeter/Stylemeter.dll.

Options > Stylemeter opens the settings: the points multiplier and every bonus.

Uninstall: delete BepInEx/plugins/Stylemeter. To remove BepInEx as well, delete winhttp.dll, doorstop_config.ini,
.doorstop_version, changelog.txt and the BepInEx folder.

Settings are also in BepInEx/config/com.glowystar.stylemeter.cfg.
How scoring works, every bonus, pictures and help: https://github.com/GlowyStar/silksong-stylemeter
